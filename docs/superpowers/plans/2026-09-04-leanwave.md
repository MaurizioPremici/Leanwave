# Leanwave Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, install, and publish a lightweight native macOS audio player that accepts YouTube URLs manually or fetches them from Chrome.

**Architecture:** A dependency-free AppKit executable owns a small native window and delegates media playback to the installed `mpv`/`yt-dlp` tools. Deterministic URL, command, theme, and IPC logic lives in a testable library; Chrome automation and the player process remain thin boundary adapters.

**Tech Stack:** Swift 6.1, AppKit, Foundation, Swift Package Manager, XCTest, `mpv` JSON IPC, `yt-dlp`, AppleScript.

**Spec:** `docs/superpowers/specs/2026-09-04-leanwave-design.md`

## Global Constraints

- Target macOS 15 on Apple Silicon.
- All user-visible copy is English.
- Do not add third-party Swift packages, Electron, WebView, or a local server.
- Play one video at a time, disable playlists, and do not persist media.
- Never close a Chrome tab or Chrome itself without the post-playback confirmation.
- Install the final bundle at `/Applications/Leanwave.app`.
- Publish source, tests, and build scripts to the public GitHub repository `MaurizioPremici/leanwave`; exclude credentials, media, caches, and build output.

- `Sources/LeanwaveCore/YouTubeURL.swift`: strict YouTube URL validation and normalized comparison.

- `Sources/LeanwaveCore/Theme.swift`: six immutable palettes and persisted identifiers.
- `Sources/LeanwaveCore/ChromeScripts.swift`: deterministic AppleScript strings and fetch-response parsing.
- `Sources/LeanwaveApp/ChromeController.swift`: AppleScript boundary and exact Chrome tab reference.
- `Sources/LeanwaveApp/PlayerController.swift`: mpv process lifecycle, IPC connection, observations, and commands.
- `Sources/LeanwaveApp/PlayerViewController.swift`: compact AppKit UI and bindings.
- `Sources/LeanwaveApp/AppDelegate.swift`: application/window lifecycle and initial Chrome fetch.
- `Sources/LeanwaveApp/main.swift`: native entry point.
- `Tests/LeanwaveCoreTests/*.swift`: deterministic unit tests.
- `Resources/Info.plist`: bundle identity and Apple Events usage text.
- `scripts/build-app.sh`: release build, app assembly, ad-hoc signing, and optional install.
- `.gitignore`: local build and macOS artifacts.
- `README.md`: prerequisites, build, install, privacy, and operation.
